# Notebooks

Notebooks are optional analysis, visualization, or teaching material only.
They are not part of the supported production workflow and must consume saved
inputs/results through production interfaces.

Phase 1 removed the historical build/run notebook chain. Its scientific and
implementation content is recorded in
`docs/v1_refactor/LEGACY_MIGRATION_INVENTORY.md` for migration during later
phases, while the original files remain recoverable from Git history.
